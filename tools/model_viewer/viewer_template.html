Mask shape

Only the Super Steve model has the mask. Shape it here, then paste the block above into tools/lib/cat_wings.py — the bake reads exactly these names. Its colour is NOT the cape panel's: the cape's red is an ambient the runtime adds around the cloth draw alone, so the mask has to carry its red in its own texture (build_cat_pack.MASK_RGBA) under the cat's blue tint. It is drawn here exactly that way.
